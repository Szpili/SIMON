Heterogeneous on purpose — and it shows

Two GPUs, two serving stacks, two models, one network. The engine and model on each result come from the signed receipt, not from a label we wrote beside it.

RTX 3090 · vLLM 0.27.1

Qwen3.8-27B · full context admission gate

64.94 tok/s

RTX 3080 Ti · Ollama 0.34.0

Bielik 11B · admission gate disabled, and the node says so

6.50 tok/s

A node that cannot verify its own context budget declares that, instead of pretending to check.

Adding the second node immediately exposed two false statements in our own receipts: the node announced a model it was not serving, and every receipt claimed vLLM even when Ollama did the work. Both fixed the same day. Heterogeneity is not a feature list here — it is a test instrument. One node could never have surfaced those two bugs.
